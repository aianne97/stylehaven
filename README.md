# Style Haven 🛍️

**Style Haven** adalah website e-commerce fashion yang dirancang untuk memberikan pengalaman berbelanja pakaian secara online dengan alur yang sederhana dan mudah digunakan.

Project ini dibuat sebagai salah satu project pengembangan web untuk menerapkan konsep **front-end development, e-commerce flow, dan user interface design**.

---

## ✨ Features

Style Haven memiliki beberapa fitur utama:

* 🔐 **Login User**
* 📝 **Register User**
* 🏠 **Homepage**
* 👕 **Kategori Produk**
* 🔎 **Detail Produk**
* 🛒 **Shopping Cart**
* 💳 **Halaman Pembayaran**

User dapat memulai dari proses login/register, melihat berbagai produk berdasarkan kategori, melihat detail produk, memasukkan produk ke dalam shopping cart, hingga melanjutkan ke proses pembayaran.

---

## 🚀 How to Run

1. Clone repository ini.

```bash
git clone https://github.com/username/style-haven.git
```

2. Masukkan folder project ke dalam folder `htdocs` jika menggunakan XAMPP.

3. Jalankan **Apache** dan **MySQL** melalui XAMPP.

4. Jika project menggunakan database, import database melalui **phpMyAdmin**.

5. Buka browser dan akses:

```text
http://localhost/Style-Haven
```
